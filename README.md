## 📋 Project Overview

This is a debt management and tracking system built as part of VDT2025 Software Engineering project. The system helps businesses track and manage their accounts receivable and payable.

## 🏗️ Architecture

- **Frontend**: Angular application with TypeScript
- **Backend**: Spring Boot application (Kotlin/Java)
- **Database**: MySQL/PostgreSQL support
- **Containerization**: Docker & Docker Compose

## 🚀 Quick Start

### Prerequisites
- Node.js (for frontend)
- Java 17+ (for backend)
- Docker & Docker Compose
- MySQL or PostgreSQL database

### Running the Application

1. **Backend**:
   ```bash
   cd backend
   ./gradlew bootRun
   ```

2. **Frontend**:
   ```bash
   cd frontend
   npm install
   ng serve
   ```

3. **Using Docker**:
   ```bash
   docker-compose up
   ```
